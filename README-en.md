# Microsoft Build //localhost:saopaulo 2026

Photos and general information about the event "Microsoft Build //localhost:saopaulo", held in São Paulo, SP.

Date: **June 20, 2026 (Saturday)**

Organizers:
- **Cynthia Zanoni (Microsoft)**
- **Renato Groffe (Microsoft MVP, Docker Captain, Grafana Champion, APIsec U Ambassador, MTAC)**
- **Chrystian Moté**
- **Eduardo Rezende**
- **Mayumi Shingaki (Microsoft MVP)**
- **Milton Camara Gomes (Microsoft MVP, MTAC)**
- **Carlos Machel (Microsoft MVP)**

Number of participants: **75 people**

We would like to register our sincere thanks to Cynthia Zanoni and FECAP for all the support provided for the event. We also thank **Chrystian Moté** and **Eduardo Rezende**, who spent much of the event taking care of check-ins.

---

Presentations/talks that took place during the event:

_# Microsoft Foundry: From Observability to ROI for AI Agents on Any Platform!_

Speaker: **Renato Groffe (Microsoft MVP, Docker Captain, Grafana Champion, APIsec U Ambassador, MTAC)**

Technologies and topics covered: **Microsoft Foundry, Agents, Artificial Intelligence, LLMs, Observability, Logs, Metrics, Traces, Azure Monitor, Application Insights, OpenTelemetry, Grafana, Azure Managed Grafana, Docker, Azure Container Registry, Visual Studio Code, Linux, .NET, C#, Python, Hosted Agents, MCP Servers, GitHub...**

_# Multi-Agent Systems with Claw and Agent Harness on Microsoft Foundry_

Speaker: **Carlos Machel (Microsoft MVP)**

Technologies and topics covered: **Microsoft Foundry, Agents, Artificial Intelligence, LLMs, .NET, C#, Claw, Agent Harness...**

_# Low-code vs Pro-code: What if You Didn’t Have to Choose? Meet Microsoft Foundry_

Speaker: **Percy Machado (Microsoft)**

Technologies and topics covered: **Microsoft Foundry, Low-Code, Artificial Intelligence, Agents, LLMs, Software Development...**

_# Your Agent, Anywhere: MultiClient and MultiDevice with GitHub Copilot SDK_

Speaker: **Mayumi Shingaki (Microsoft MVP)**

Technologies and topics covered: **Artificial Intelligence, Agents, Productivity, GitHub Copilot, Visual Studio Code, GitHub, .NET, C#, ASP.NET Core...**

_# AI Agents in Production: Deployment and Scalability with Azure Container Apps_

Speaker: **Milton Camara Gomes (Microsoft MVP, MTAC)**

Technologies and topics covered: **Azure Container Apps, Azure Container Apps Sandboxes, Kubernetes, Cloud Native, KEDA (Kubernetes Event-driven Autoscaling), Azure Container Registry, Linux, Containers, Docker, Artificial Intelligence, Agents, Microsoft Foundry...**
